# Pass 2 Re-pass: Wider Subclass Fits

Binding instructions for the re-pass agents. The user ruled (Session 48) that cleric domains, paladin oaths and warlock patrons not yet reprinted in a 2024-format book are available, minus Plane Shift and World of Warcraft. The list is in `setting-compendium-pass2-brief.md`, section "Available 2024 subclasses". The pages were drafted against only the four 2024 Player's Handbook options per class. This re-pass updates the derived fits.

## What to do on each assigned page

1. Read the page, then read `setting-compendium-pass2-subclass-reference.md` for the 14 domains, 10 oaths and 10 patrons. Read the full reference once. It gives each option's source, feature names, theme and spells. Use it to describe an option accurately; do not describe a class feature from memory.
2. In the page's `Using X as a Deity` (or `Patron`) box, rewrite the **cleric**, **paladin** and **warlock** bullets so that each names the best fit among the available options. Keep each bullet's existing label and position. Mark the fit `(derived)` and give its source in brackets the first time it appears, for example `Forge Domain (derived; Xanathar's Guide to Everything)`.
3. Choose by the power's own portfolio, domains (the metadata block's 5etools domains are 2014 labels) and the page's sourced material. A strong theme match beats a convenient one. Say why in one sentence. Where two options fit, name the second as the alternative in one clause. If nothing fits, say so plainly ("No oath fits"); do not force a fit.
4. Keep the Divine Order line for the cleric: Protector or Thaumaturge, whichever fits, with a one-clause reason. This still applies for every domain.
5. For a power whose fit was the fixed fallback ("No warlock connection in the sources"), keep the fallback unless an available patron plainly matches the sources. A Fiend patron for an evil god is not a source-based connection; a patron whose page or wiki text names the power (as the Iggwilv and Baba Yaga pages do) is.
6. Patron pages: keep the warlock bullet first. The cleric-or-paladin line may split into a cleric line and a paladin line when an available option fits; otherwise keep it as one line.
7. Update the page's `Derived` bullet in Draft Notes so it lists the new fits. Delete any Draft Notes bullet that says a fit is "from memory of the 2024 PHB", and any sentence in the page that describes a class feature the reference does not support.
8. If the Overview or GM Notes mention the old fit, fix them. Change nothing else on the page.
