# Waterdeep NPC ethnicity table

Date: 2026-11-18. Replaces the label "Waterdhavian Human" (a city, not an ethnicity) on invented NPCs. Source of the ethnicity list and the Dragon Heist (DH) spread: `docs/plans/faerun-ethnicities-research.md`.

## How the assignments were made

- **Allowed labels.** Only ethnicities the sources list: Illuskan, Chondathan, Tethyrian, Turami, Calishite, Damaran, Mulan, Chultan (DH). No city or region is used.
- **Name pattern.** None of the invented names appears in a SCAG or FRHoF name list (research, "The caller's invented names against the name lists"). FRHoF has no name lists, and SCAG lists only Arkaiun, Bedine, Ffolk, Gur, Halruaan, Imaskari, Nar, Shaaran, Tuigan and Ulutiun names. "Name pattern" below therefore means a resemblance to the Player's Handbook ethnicity name lists (Italianate for Turami, Arabic for Calishite, Slavic "-sk" surnames for Damaran, compound English surnames for Chondathan, Norse-English for Illuskan). The Player's Handbook is not in `sources/5etools/`, so that resemblance is a judgment call. The DH spread is the tie-breaker.
- **DH spread.** Of the roughly 60 DH Waterdeep NPC labels in the research table, Illuskan is the most common (about 22), then Tethyrian (about 19), then Turami and Chondathan (about 5 each), with Calishite, Mulan, Shou, Damaran and a few others at one to three each. The 34 NPCs below came out at Illuskan 14, Tethyrian 9, Chondathan 5, Turami 3, Damaran 2, Calishite 1, which keeps that order.
- **Stat-line form.** Capitalized ("Illuskan Human"), as before. Prose mentions use the lowercase form already in use ("an Illuskan human").
- **Line numbers** are the lines edited; nothing shifted, because every edit stayed on one line.
